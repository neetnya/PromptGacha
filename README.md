# PromptGacha · 提示词抽卡器

一键抽出「女性外观特征」和「服装 / 姿势 / 表情 / 场景」，拼成可直接喂给 Anima / SD 系模型的提示词。

| 抽什么 | 输出示例 |
|---|---|
| 女性外观特征（发色 / 瞳色 / 发型 / 体型 / 兽耳等），**只有特征，不含角色名** | `1girl, blue eyes, short hair, white hair, hairband, katana` |
| 服装 + 姿势 + 表情 + 场景，按等级筛选并经合理性校验 | `underbust, layered black miniskirt, slit throat gesture, in car, sunset` |

由开源项目:[Comfyui-Anima-Wardrobe](https://github.com/lingdongbudong/Comfyui-Anima-Wardrobe)，改造而来

## 运行

依赖：**.NET 8 桌面运行时** + **本机 Python 3.8+**（无第三方包）。

```bat
dotnet build -c Release
bin\Release\net8.0-windows\PromptGacha.exe
```

`python` 按环境变量 `PATH` 找（找不到才退回系统自带的 `py -3`）；引擎固定用 exe 同级的 `engine\`（生成时自动拷贝）。
两项都在启动时自动确定，界面上不提供设置。缺 Python 或引擎不完整时，日志区第一行会给出提示。

## 界面

左侧上方是一张「抽卡设置」卡片，左下是日志，右侧是提示词，底部是按钮。

| 区域 | 内容 |
|---|---|
| 抽卡设置 · 顶部一行 | 等级 / 连抽（全局开关） |
| 抽卡设置 · 角色 · 女性特征 | 池 / 关系 / 人数 + 强制巨乳、关闭避重 |
| 抽卡设置 · 装扮 · 服装 / 姿势 / 表情 / 场景 | 不抽服装 / 姿势 / 表情 / 场景、允许公共场合暴露 |
| 日志 | 每次抽卡自动清空，重新写入本次的执行过程 |
| 提示词 | 结果区，右上角可 `复制` / `保存…` |

### 底部按钮

| 按钮 | 作用 |
|---|---|
| `抽角色` | 只抽女性特征，输出 `1girl` + 特征标签 |
| `角色 + 装扮` | 先抽角色，再给每个角色配一套服装 / 姿势 / 表情 / 场景。一步得到完整提示词，一般用这个（主按钮，蓝色） |
| `抽装扮` | 只抽一套服装 / 姿势 / 表情 / 场景。**不含人物标签**，输出里没有 `1girl` |
| `取消` | 中断正在运行的引擎进程 |

抽卡进行中三个抽卡按钮会禁用，只有 `取消` 可用；完成后状态栏显示耗时。

> 按钮背后仍是引擎的两个子命令 `girl` / `roll`，日志里也沿用这两个词。

## 参数

### 等级 / 连抽（卡片顶部）

| 项 | 默认 | 说明 |
|---|---|---|
| 等级 | `any` | 内容等级，见下表。主要影响装扮的抽取范围，也会影响角色在多人时的关系标签 |
| 连抽 | `1` | 一次抽几组，`1`~`99`。结果区用 `====` 分隔，日志逐组追加 |

#### 等级表

| 取值 | 含义 |
|---|---|
| `sfw` | 全年龄，无任何暴露向标签 |
| `suggestive` | 擦边：露肩 / 短裙 / 内衣轮廓 / 材质诱惑 |
| `explicit` | 成人：明显裸露或透视，全裸 / 内衣外露 / 半脱 |
| `hardcore` | 过激：性行为 / 性道具 / 体液 / 束缚 |
| `extreme` | 极端：群体 / 极限扩张 / 拘束装置 / 主奴标记 |
| `any` | 不限，按顶格处理场所承载力 |

### 角色（girl）

| 项 | 默认 | 说明 |
|---|---|---|
| 池 | `热门 TOP200` | `热门 TOP200` / `热门 TOP1000` / `全部女性`（5981 条）。池按角色热度降序，选哪个决定候选范围 |
| 关系 | `auto（按等级）` | 人数 ≥ 2 时追加的关系标签：`auto` 按等级决定 / `normal` 正常互动 / `yuri` 百合 / `none` 不加 |
| 人数 | `1` | `1` / `2` / `3`。多条特征合并成一串（自动去重），人数词相应变成 `2girls` / `3girls` |
| 强制巨乳 | 关 | 删掉所有体型词（`small/medium/large/gigantic breasts`、`flat chest` 等），统一补 `huge breasts` |
| 关闭避重 | 关 | 默认会避开最近 40 次抽过的档案（候选不够时才允许重复）；勾上则完全随机 |

抽的是角色档案里的**特征标签**，档案里的角色名与作品名只写进日志的「来源」行（用于避重和追溯），
不会进入提示词——所以抽出来的是「一个女性长什么样」，而不是某个具体角色。

### 装扮（roll）

| 项 | 默认 | 说明 |
|---|---|---|
| 不抽服装 / 不抽姿势 / 不抽表情 / 不抽场景 | 都抽 | 单独关掉某一项，其余照样抽 |
| 允许公共场合暴露 | 关 | 允许暴露向服装出现在半公开 / 公共场所。不开时这类组合会被判为违规 |

抽完会做三项一致性校验：服装搭配是否自相矛盾、场所隐私等级能否承载服装暴露度、场景细节是否与等级相符。
不通过时日志里会标 `⚠ 违规`，提示词仍然输出。

四项全部关掉时提示词为空，日志仍会走一遍流程，状态栏报失败。

## 输出

右侧提示词区是纯文本，可直接全选复制，或点 `复制` 复制全部内容、`保存…` 存成 `.txt`。

上方小字显示本次条数。连抽多组时，各组之间有空行和分隔标题，方便整段粘进 ComfyUI。

## 排错

| 现象 | 处理 |
|---|---|
| 日志第一行提示「找不到 Python」 | 把 Python 加入系统环境变量 `PATH`，或安装 Python 时勾选 Add to PATH |
| 弹窗提示「软件目录下没有 anima_cli.py」 | `engine\` 没被拷到 exe 旁边。重新 `dotnet build`，或手动把 `engine\` 复制到 exe 同级 |
| 启动就崩、窗口都没出来 | 看 `%APPDATA%\PromptGacha\error.log` |
| 老抽到同一批特征 | 检查是否勾了「关闭避重」。避重记录在 `engine\presets\.recent_girls.json`，删掉即清空记忆 |
| 抽卡很慢 | 每次抽卡都要起一次 Python 进程，冷启动约 1 秒；连抽组数多时按组数累加 |
